Important:
- Existing localStorage key cket_demo_users is preserved, so this update reads the same accounts and point balances in the same browser.
- Data remains browser-local and will not sync between devices.
- The naira figure is an illustrative display only. CKET points are not cash, not redeemable, and cannot be withdrawn.
- Deposit and withdrawal screens do not collect or process payments.
- The market is a simulated price display only; it does not buy or sell assets.
- Paid random spins are not implemented. The rewards page explains the fixed daily activity reward.
- Do not use this localStorage login system for a public production service. A secure backend and security review are needed before public launch.
